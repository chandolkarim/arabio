# 아라비오 (Arabio)

> 하루 세 대화로, 푸스하로 아는 문장을 이집트·요르단·사우디 방언으로 꺼내 말하게 하는 아랍어 학습 웹 앱

- **공개 주소**: https://arabio-xi.vercel.app (같은 내용을 https://chandolkarim.github.io/arabio/ 에서도 엽니다)
- **저장소**: https://github.com/chandolkarim/arabio
- 2026학년도 2학기 기술개발연구프로젝트 · 최종 프로젝트 · 한국외국어대학교 아랍어과 정찬민

---

## 1. 목적

한국뿐 아니라 어디를 가든 우리가 배우는 아랍어는 푸스하(표준 아랍어)이고, 특히 문법과 독해 위주로 배워서 말하거나 들을 기회가 많지 않습니다. 그런데 막상 외국에 나가서 살면 "아, 정말 여태 뭘 배운 거지…"라는 생각이 듭니다. 현지인들은 모두 각자 지역 방언(암미야)을 쓰기 때문입니다. 저도 외국에 나가 살 때 암미야를 몰라서 현지 사람들과 소통이 되지 않아 상당히 힘들었습니다.

### 왜 암미야인가

아랍어는 **두 가지 말이 함께 쓰이는 언어**입니다.

- **푸스하**: 뉴스, 책, 공문서, 공식 연설에서 쓰는 글말이자 격식 있는 말입니다. 아랍 사람들도 학교에 가서야 배우고, 일상 대화에서는 거의 쓰지 않습니다.
- **암미야(방언)**: 아랍 사람들이 집에서 처음 배우는 진짜 모국어입니다. 가족·친구와 대화할 때, 가게에서 물건을 살 때, 택시를 탈 때, 드라마와 노래, SNS까지 일상은 모두 암미야로 이루어집니다.

그래서 푸스하만 배운 사람은 현지에서 **"책은 읽는데 대화는 못 하는"** 상태가 됩니다. 푸스하로 말을 걸면 상대는 알아듣더라도 뉴스 앵커처럼 딱딱하게 들리고, 상대가 암미야로 대답하면 이번에는 제가 알아듣지 못합니다. 제가 외국에서 지내며 겪은 어려움이 바로 이것이었습니다.

암미야는 나라와 지역마다 다르지만, 같은 문장에서 무엇이 바뀌는지 규칙이 있습니다. 예를 들어 "어떻게 지내?"는 푸스하로 كيف حالك(케이파 할루?)이지만 이집트에서는 عامل إيه(아-밀이ㅎ), 요르단에서는 كيفك(케이픽크?)라고 합니다. 그래서 아라비오는 이미 아는 **푸스하 문장을 기준으로 방언 문장을 나란히 비교**하게 했습니다. 푸스하를 배운 학습자가 그 지식을 버리지 않고 그대로 디딤돌로 쓸 수 있도록요.

학교 수업에서도 교수님께서 실제 소통을 위해 암미야가 얼마나 중요한지 강조해 주셨습니다. 이 서비스에 대해서도 방언으로 말하는 것을 목표로 두고 푸스하를 비교와 이해의 바탕으로 삼는 방향이 요즘 아랍어 교육의 실용적인 흐름과 맞는다는 조언을 해 주셔서, 이 방향으로 계속 다듬고 있습니다.

그래서 **문장 단위로 푸스하와 암미야 표현을 함께 외워서, 유학을 가든 현지에서 일을 하든 현지 사람들과 소통할 수 있게** 하는 것을 목표로 아라비오를 만들었습니다. 같은 대화를 푸스하와 방언으로 나란히 비교하고, 그 방언 문장을 듣고, 조립하고, 직접 말해 보면서 익힙니다. 하루 세 대화씩 100일 동안 300개의 대화를 익힙니다.

## 2. 사용자

**아랍어과 학생 모두**를 위해 만들었습니다. 푸스하는 배웠지만 암미야를 몰라서, 현지 사람들의 말을 알아듣고 말하는 데 막히는 학생들입니다.

- **줄이려는 불편**: 학교에서 푸스하로만 배워서 암미야를 모르는 것. 그래서 현지에 가면 알아듣지도 말하지도 못하는 것.
- **대상이 아닌 사람**: 푸스하를 처음 배우는 사람. 이 앱은 푸스하 문장을 기준으로 방언을 비교하기 때문에, 첫 화면에서 "푸스하가 처음이라면 기초 문법을 먼저 익히고 오면 훨씬 수월해요"라고 안내합니다.
- 방언은 **이집트**, **요르단**, **사우디** 중에서 고릅니다. 진도는 방언별로 따로 저장됩니다.

**핵심 흐름(하루 학습 한 번)**: 처음 방문 안내 → 홈에서 오늘 할 날 선택 → 15단계 레슨 → 하루 완료(진도·경험치·복습 일정 저장).

## 4. 사용법

1. 공개 주소를 엽니다. 처음이면 안내 화면에서 **시작하기**를 누릅니다.
2. 홈 위쪽에서 배울 방언(**이집트 / 요르단 / 사우디**)을 고릅니다. 사진과 색이 나라에 맞게 바뀝니다.
3. 학습 경로에서 오늘 할 날의 **학습 시작**을 누릅니다. 하루 학습은 15단계입니다.
   - **1~6단계 · 대화 보기와 표현 비교**: 푸스하 대화를 읽고 들은 뒤, 같은 대화를 방언으로 보며 바뀐 핵심 표현을 비교합니다. 아랍어 단어나 숙어를 누르면 뜻이 나옵니다.
   - **7~12단계 · 연습**: 대화마다 ① 음성을 듣고 뜻 고르기, ② **단어 블록을 눌러 방언 문장 완성하기**를 풉니다.
   - **13~15단계 · 말하기**: 한국어만 보고 방언으로 말해 봅니다. **녹음하며 말하기**를 누르면 내 목소리와 원어민 음성을 번갈아 들을 수 있습니다. **AI로 발음 확인하기**를 누르면 AI가 받아쓴 내 말과 정답 문장을 비교해 일치도(%)와 맞은 단어(초록)·놓친 단어(빨강)를 보여 줍니다. 정답을 확인한 뒤 "말할 수 있어요 / 헷갈려요"를 고릅니다.
4. 레슨 화면 위쪽의 **속도 버튼(1.0×)**을 누르면 음성 속도가 0.7 → 0.8 → 1.0 → 1.1 → 1.2배로 바뀝니다.
5. **하트 규칙**: 하트는 최대 5개이고, 새 학습(또는 끝낸 날 다시 학습)에서 문제를 틀릴 때마다 1개씩 줄어듭니다.
   - 하트가 0개가 되면 **그날 학습만 멈추고 저장되지 않습니다.** 앞서 끝낸 날의 진도와 경험치는 그대로 남고, 1일차로 돌아가지 않습니다.
   - 하트를 다시 채우는 방법은 두 가지입니다. ① 방금 틀린 문장(최대 3개)을 연습하면 5개가 모두 찹니다. ② 기다리면 3시간마다 1개씩 생깁니다.
   - 하트를 채운 뒤 나오는 **"N일차 다시 시작"**은 멈췄던 그날을 처음부터 다시 하는 버튼입니다.
   - 복습과 하트 채우기 연습은 틀려도 하트가 줄지 않고, 복습을 마치면 하트 1개를 받습니다.
6. 하루를 마치면 진도와 경험치가 저장되고, 틀리거나 헷갈린 문장은 다음 날 **복습** 탭에 나옵니다. 기억한 문장은 1·3·7·14·30일 간격으로 다시 나옵니다.
7. **기록** 탭에서 완료한 날과 단원 도장을, **설정** 탭에서 진도 초기화·음성 속도·하루 목표·효과음을 바꿉니다. 방언은 홈 위쪽 버튼으로 바꿉니다.

### 개인정보와 보안

- **회원가입·로그인·서버가 없습니다.** 학습 진도는 사용하는 기기의 브라우저 저장소(localStorage)에만 저장되고 어디로도 보내지 않습니다.
- **녹음한 목소리는 기기 메모리에만 잠깐 있고** 저장하지 않습니다. 다음 레슨으로 넘어가면 지워집니다.
- **AI 발음 확인(12주차 추가)**: 사용자가 **AI로 발음 확인하기**를 누를 때만 그 녹음 하나를 Vercel 함수(`web/api/check-speech.js`)를 거쳐 오픈하사 Whisper로 보내 받아씁니다. 버튼 바로 아래에 이 사실을 적었고, 함수는 녹음과 받아쓴 글을 저장하거나 로그에 남기지 않습니다. 누르지 않으면 녹음은 기기 밖으로 나가지 않습니다.
- 오픈하사 키(`HASA_API_KEY`)는 **Vercel 환경 변수**와 제 컴퓨터의 `.env.local`(저장소 최상위, `.gitignore`에 포함)에만 있고 코드·저장소·화면에는 없습니다.
- 음성을 만들 때 쓴 **Sawtak API 키는 저장소 밖의 제 컴퓨터 설정 파일에만** 있고 코드·저장소에 넣지 않았습니다. 배포된 앱은 미리 만들어 둔 음성 파일만 재생하므로 실행 중에 키가 필요 없고, 그래서 GitHub Secrets에도 넣을 키가 없습니다.
- 검수용 페이지(`admin.html`)는 제 컴퓨터(localhost)에서만 열리고, 공개 주소에서는 안내 문구만 나옵니다.

## 7. 알려진 한계

- **방언은 이집트·요르단·사우디 세 가지입니다.** 마그레브(모로코) 방언은 아직 없습니다. 다른 방언보다 알아듣기 어렵고 프랑스어 단어가 많이 섞여 있어서, 검수할 시간을 충분히 확보한 뒤 추가할 계획입니다.
- **사우디 문장은 리야드(나즈드) 말 기준입니다.** 제다(히자즈) 등 다른 지역과는 표현이 다를 수 있습니다.
- **음성은 원어민 녹음이 아니라 AI 음성 합성(TTS)입니다.** 틀린 음성이 있어서 전부 직접 들어 보고 확인해서 다시 만들었습니다. 다만 원어민이 녹음한 것만큼 자연스럽지는 않을 수 있습니다.
- **말하기 AI 채점은 받아쓰기 기준입니다.** 오픈하사 Whisper가 받아쓴 글과 정답 방언 문장을 단어별로 비교하므로 발음의 세밀한 차이(억양, 장모음 길이)는 점수에 다 드러나지 않습니다. 점수는 참고용이고, '말할 수 있어요 / 헷갈려요'는 여전히 학습자가 고릅니다. AI 채점은 Vercel 주소(arabio-xi.vercel.app)에서만 되고, 서버 함수가 없는 GitHub Pages 주소에서는 버튼이 나오지 않습니다. 개발키 한도(분당 10회, 하루 500건)를 넘으면 잠시 뒤 다시 하라고 안내합니다.
- **진도가 기기 브라우저에만 저장됩니다.** 다른 기기와 이어지지 않고, 브라우저 데이터를 지우면 진도도 지워집니다.
- **교수님께서 조언해 주신 "아랍어 자판으로 직접 입력하는 문제"는 아직 없습니다.** 복습용 도전 문제로 추가할 예정입니다.
- 오프라인에서는 한 번 열어 본 화면과 한 번 들은 음성만 쓸 수 있습니다. 처음 듣는 음성은 인터넷이 필요합니다.
- 녹음 기능은 브라우저의 마이크 권한이 필요하고, 권한을 막으면 안내만 나옵니다.

## 11. 사용한 자료와 AI 도움

**AI에게 맡긴 일과 제가 한 일**: AI로 문장을 뽑고 음성을 만들었고, 저는 문장 검수와 음성 검수를 직접 다 했습니다. 또 학습 구성에서 부족한 점을 제가 다 잡아냈습니다. 예를 들면 다음과 같습니다.
- 처음 만든 1번 문장의 푸스하 답이 부자연스러운 것을 찾아 기본 표현으로 고쳤습니다.
- 단어를 누르면 나오는 뜻에서 부정어(ما…ش) 뒤 동사에 "못/안"이 들어가 있던 문제, 숙어를 단어 하나하나로 쪼개 보여 주던 문제를 잡아냈습니다.
- 설명이 "현재 부정: ما بتسألش"처럼 형태를 알 수 없게 적혀 있어서 "ما + 동사 + ش" 식으로 다시 쓰게 했습니다.
- 연습 문제가 보기 고르기 위주라 너무 쉽고, 문장 만들기 문제가 하루에 하나뿐이라는 점을 잡아서 늘렸습니다.
- 교수님(김대환 교수님)께 방언 음성 합성 방법(Sawtak 추천), 학습 구성(방언 말하기 목표), 음성 속도에 대해 조언을 받아 반영했습니다.
- 디자인을 여러 번 다시 만들게 했고, 고양이 선생님(제 고양이 꾸꾸, 친구 고양이 아꿍)을 기획해 사진을 제공했습니다.

**사용한 AI 도구**
- **Claude Code (Anthropic)**: 웹 앱 코드 작성, 대화 300개의 아랍어 초안과 사우디 버전 초안, 단어 뜻·숙어·설명 초안, 음량 정리 스크립트, 자동 테스트, 배포 설정, 이 README 정리
- **ChatGPT / Codex (OpenAI)**: 나라 사진 배경 홈 화면 디자인, 음성 받아쓰기 점검(Whisper)과 이상 음성 재생성, 고양이 선생님 그림 생성
- **Sawtak**: 아랍어 방언 음성 합성

**AI를 쓰면서 조심한 점**: 음성 쪽에 틀린 것이 꽤 있었습니다. 엉뚱한 말이 덧붙거나 발음이 이상한 파일이 있어서, 하나하나 확인해서 다시 만들어야 했습니다. 그래서 AI가 만든 결과는 그대로 믿지 않고 직접 듣고 보면서 확인했습니다.

# 아라비오 (Arabio)

> 하루 세 대화로, 푸스하로 아는 문장을 이집트·요르단 방언으로 꺼내 말하게 하는 아랍어 학습 웹 앱

- **공개 주소**: https://chandolkarim.github.io/arabio/
- **저장소**: https://github.com/chandolkarim/arabio
- 2026학년도 2학기 기술개발연구프로젝트 · 중간 MVP · 한국외국어대학교 아랍어과 정찬민

---

## 1. 목적

한국의 아랍어 학습자는 문법과 단어는 꽤 알아도, 막상 말하려고 하면 막히는 경우가 많습니다. 수업과 교재가 대부분 푸스하(표준 아랍어) 중심인데, 실제 아랍 사람들은 일상에서 이집트·요르단 같은 방언(암미야)으로 말하기 때문입니다. 저도 아랍어과에서 공부하면서 "글로 보면 아는데 들으면 모르고, 아는 문장도 입으로는 안 나오는" 문제를 계속 느꼈습니다.

아라비오는 **같은 대화를 푸스하와 방언으로 나란히 비교**하고, 그 방언 문장을 **듣고, 조립하고, 직접 말해 보게** 해서 "실제로 꺼내 쓸 수 있는 문장"으로 만드는 것을 목표로 합니다. 하루 세 대화씩 100일 동안 300개의 대화를 익힙니다.

## 2. 사용자

**푸스하 기초(문자·기초 문법·기본 단어)를 배웠지만 방언으로 말하는 데 막히는 한국인 아랍어 학습자**를 대상으로 합니다. 대표적으로 아랍어과 1~2학년 학생, 중동 교환학생·여행을 준비하는 사람입니다.

- 아랍어를 처음 배우는 사람은 대상이 아닙니다. 첫 화면에서 "푸스하가 처음이라면 기초 문법을 먼저 익히고 오면 훨씬 수월해요"라고 안내합니다.
- 방언은 학습자가 많이 쓰는 **이집트**와 **요르단** 두 가지 중에서 고릅니다. 진도는 방언별로 따로 저장됩니다.

**줄이려는 불편**: 푸스하로만 배워서 실제 대화에서 방언을 못 알아듣고 말하지 못하는 것, 그리고 방언 자료가 흩어져 있어 푸스하와 무엇이 다른지 한눈에 비교하기 어려운 것.

**핵심 흐름(하루 학습 한 번)**: 처음 방문 안내 → 홈에서 오늘 할 날 선택 → 15단계 레슨 → 하루 완료(진도·경험치·복습 일정 저장).

## 3. 공개 주소

https://chandolkarim.github.io/arabio/

- GitHub Pages로 배포합니다. `main` 브랜치에 올리면 GitHub Actions가 `web/` 폴더를 자동으로 배포합니다.
- 휴대폰 브라우저에서 쓰는 것을 기준으로 만들었고, 컴퓨터 브라우저에서도 열립니다. 별도 설치나 로그인은 필요 없습니다.

## 4. 사용법

1. 공개 주소를 엽니다. 처음이면 안내 화면에서 **시작하기**를 누릅니다.
2. 홈 위쪽에서 배울 방언(**이집트 / 요르단**)을 고릅니다. 사진과 색이 나라에 맞게 바뀝니다.
3. 학습 경로에서 오늘 할 날의 **학습 시작**을 누릅니다. 하루 학습은 15단계입니다.
   - **1~6단계 · 대화 보기와 표현 비교**: 푸스하 대화를 읽고 들은 뒤, 같은 대화를 방언으로 보며 바뀐 핵심 표현을 비교합니다. 아랍어 단어나 숙어를 누르면 뜻이 나옵니다.
   - **7~12단계 · 연습**: 대화마다 ① 음성을 듣고 뜻 고르기, ② **단어 블록을 눌러 방언 문장 완성하기**를 풉니다.
   - **13~15단계 · 말하기**: 한국어만 보고 방언으로 말해 봅니다. **녹음하며 말하기**를 누르면 내 목소리와 원어민 음성을 번갈아 들을 수 있습니다. 정답을 확인한 뒤 "말할 수 있어요 / 헷갈려요"를 고릅니다.
4. 레슨 화면 위쪽의 **속도 버튼(1.0×)**을 누르면 음성 속도가 0.7 → 0.8 → 1.0 → 1.1 → 1.2배로 바뀝니다.
5. 하루를 마치면 진도와 경험치가 저장되고, 틀리거나 헷갈린 문장은 다음 날 **복습** 탭에 나옵니다. 기억한 문장은 1·3·7·14·30일 간격으로 다시 나옵니다.
6. **기록** 탭에서 완료한 날과 단원 도장을, **설정** 탭에서 방언 변경·진도 초기화·음성 속도를 확인합니다.

### 개인정보와 보안

- **회원가입·로그인·서버가 없습니다.** 학습 진도는 사용하는 기기의 브라우저 저장소(localStorage)에만 저장되고 어디로도 보내지 않습니다.
- **녹음한 목소리는 기기 메모리에만 잠깐 있고**, 서버에 보내거나 저장하지 않습니다. 다음 레슨으로 넘어가면 지워집니다.
- 음성을 만들 때 쓴 **Sawtak API 키는 저장소 밖의 제 컴퓨터 설정 파일에만** 있고 코드·저장소에 넣지 않았습니다. 배포된 앱은 미리 만들어 둔 음성 파일만 재생하므로 실행 중에 키가 필요 없고, 그래서 GitHub Secrets에도 넣을 키가 없습니다.
- 검수용 페이지(`admin.html`)는 제 컴퓨터(localhost)에서만 열리고, 공개 주소에서는 안내 문구만 나옵니다.

## 7. 알려진 한계

- **음성은 원어민 녹음이 아니라 AI 음성 합성(TTS)입니다.** 자동 받아쓰기로 이상한 음성을 찾아 다시 만들었지만, 사람이 모든 방언 발음을 확인하지는 못했습니다. 검수를 계속하고 있습니다.
- **대화·단어 뜻·숙어·설명이 아직 "검수 대기" 상태입니다.** AI 초안에서 출발했기 때문에, 검수 중 틀린 뜻이나 어색한 표현이 나올 수 있습니다.
- **말하기는 자동 채점하지 않습니다.** 녹음 비교와 스스로 평가하기로 대신합니다.
- **진도가 기기 브라우저에만 저장됩니다.** 다른 기기와 이어지지 않고, 브라우저 데이터를 지우면 진도도 지워집니다.
- **교수님께서 조언해 주신 "아랍어 자판으로 직접 입력하는 문제"는 아직 없습니다.** 복습용 도전 문제로 추가할 예정입니다.
- 인터넷 없이 쓰는 오프라인 모드는 지원하지 않습니다.
- 녹음 기능은 브라우저의 마이크 권한이 필요하고, 권한을 막으면 안내만 나옵니다.

## 8. 사용한 자료와 AI 도움

### 제가 직접 한 것
- 주제 선정과 방향 결정: 문장 단위 학습, 푸스하 → 방언 비교, 하루 세 대화, 이집트·요르단 두 방언, 진단평가와 말하기 자동 채점 제외
- 교수님(김대환 교수님) 상담: 방언 음성 합성 방법(Sawtak 추천), 학습 구성(방언 말하기 목표), 음성 속도에 대한 조언을 받아 반영
- 아랍어 내용 검토: 1번 문장의 부자연스러운 표현을 발견해 고쳤고, 음성을 직접 들어 이상한 파일 4개를 찾아 다시 만들게 했습니다.
- AI가 만든 내용에서 오류 유형을 찾아 고치도록 지시: 부정어(ما…ش) 뒤 동사 뜻, 숙어는 한 덩어리로 뜻 보여 주기, 설명을 "형태 공식" 중심으로 다시 쓰기
- 디자인 피드백: 처음 디자인이 촌스럽다고 판단해 여러 번 다시 만들게 했고, 친구들의 의견(나라별 색 구분)을 반영했습니다.
- 고양이 선생님 기획과 사진 제공(제 고양이 꾸꾸, 친구 고양이 아꿍)

- **ChatGPT / Codex (OpenAI)**: 나라 사진 배경 홈 화면 디자인, 음성 받아쓰기 점검(Whisper)과 이상 음성 재생성, 고양이 선생님 그림 생성
- **Sawtak**: 아랍어 방언 음성 합성
- AI가 만든 결과는 제가 화면에서 직접 확인했고, 틀린 부분은 위처럼 지적해 고쳤습니다. 아랍어 내용의 최종 검수 책임은 저에게 있으며 검수가 진행 중입니다.

아라비오 소개 · 개인정보 처리방침

시행일 2026년 10월 16일

아라비오는

푸스하(표준 아랍어)를 배운 학습자가 같은 대화를 이집트·요르단 방언으로 비교하며 듣고, 단어로 조립하고, 직접 말해 보도록 만든 아랍어 학습 앱이에요. 하루 대화 3개씩 100일, 300개의 대화를 익혀요.

한국외국어대학교 아랍어과 정찬민이 2026학년도 2학기 기술개발연구프로젝트로 만들었어요.

한눈에 보기

  • 회원가입·로그인이 없고, 개인정보를 수집하지 않아요.
  • 학습 기록은 지금 쓰는 기기의 브라우저에만 저장돼요.
  • 녹음한 목소리는 어디에도 보내거나 저장하지 않아요.
  • 광고와 이용 분석 도구를 쓰지 않아요.

1. 기기에 저장하는 정보

학습 진도, 복습 일정, 경험치, 연속 학습 기록, 하트, 하루 목표와 음성 속도 같은 설정을 브라우저 저장소(localStorage)에 저장해요. 이 정보는 기기 밖으로 보내지 않아요.

인터넷 없이도 열리도록 앱 화면, 문장 데이터, 들은 음성 파일을 브라우저 캐시에 저장해요. 이 파일들은 모든 사용자에게 같은 학습 자료이고 개인정보가 아니에요.

2. 마이크와 녹음

말하기 단계에서 녹음하며 말하기를 누를 때만 마이크 권한을 요청해요. 녹음은 원어민 음성과 비교해 듣도록 기기 메모리에만 잠깐 있고, 다음 학습으로 넘어가면 지워져요. 서버로 보내거나 파일로 저장하지 않아요.

3. 진도 백업

설정의 진도 백업으로 만든 코드나 파일에는 위 1번의 학습 기록과 설정만 들어 있어요. 아라비오는 이 백업을 따로 보관하지 않으니 직접 안전한 곳에 두세요.

4. 이용하는 외부 서비스

  • GitHub Pages: 앱을 배포하는 곳이에요. 접속할 때 GitHub가 기술적인 접속 기록을 남길 수 있어요(GitHub 개인정보 처리방침).
  • Google Fonts, jsDelivr: 글꼴을 받아 와요. 글꼴을 요청할 때 해당 서비스에 IP 주소 같은 기본 접속 정보가 전달될 수 있어요.

5. 기록 지우기

앱의 설정 → 진도 초기화로 지금 방언의 진도를 지울 수 있어요. 모든 기록과 저장된 파일을 지우려면 브라우저 설정에서 이 사이트의 데이터를 삭제하세요.

6. 자료 출처

  • 대화 300개: 상황을 정해 AI(Claude)와 함께 문장을 만들고 직접 검수했어요.
  • 음성 1,800개: Sawtak 아랍어 음성 합성(푸스하 아이만, 이집트 아슈라프, 요르단 야잔)으로 만들고 직접 들어 검수했어요.
  • 나라 사진: Giza Pyramids Panorama · Benjamin Inbar (CC BY-SA 4.0), Petra Treasury · David Bjorgen (CC BY-SA 3.0). 잘라내고 색을 보정했어요.
  • 고양이 선생님 그림: 만든 사람의 고양이와 친구 고양이 사진을 바탕으로 AI 이미지 생성으로 그렸어요.
  • 글꼴: Pretendard, Amiri, Noto Naskh Arabic, Noto Serif KR (SIL Open Font License)
